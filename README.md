# STM32 Bluetooth RC Control

Bluetooth 기반 RC카 제어와 Arduino–STM32 연동을 구현한 임베디드 통신·제어 프로젝트

## 주요 기능

- Bluetooth 기반 RC카 원격 제어
- UART 및 TCP/IP 기반 명령 전달
- 초음파 센서 기반 장애물 감지 및 자동 정지
- Python 브릿지를 통한 통신 데이터 중계
- STM32 LED를 이용한 주행 상태 표시

## 사용 기술

`STM32` `Arduino` `UART` `TCP/IP` `Bluetooth` `Python Bridge`
